# Handy-Test v2.15.0 (Saetze auslassen, Auswertung)

Vorher: BEIDE Handys ganz schliessen und neu oeffnen, unter Settings steht 2.15.0.

## Saetze auslassen (Person mit 3 Saetzen je Uebung)
- [ ] Training starten, Uebung antippen: neben "Speichern" steht
      "Satz 1–3 auslassen"
- [ ] Satz 1 und 2 speichern, auf Satz 3 steht "Satz 3 auslassen" — tippen:
      das Rad geht weiter (zur anderen Person oder schliesst), unten steht
      "...: Satz 3 ausgelassen" mit "Rückgängig"
- [ ] Auf der Karte ist der dritte Punkt durchgestrichen
- [ ] "Rückgängig" innerhalb von 5 Sekunden: der Punkt ist wieder leer
- [ ] Bei einer anderen Uebung nach Satz 1 auslassen: "Satz 2–3 auslassen",
      danach zwei durchgestrichene Punkte
- [ ] Uebung erneut antippen, Reiter "Satz 3" (gestrichelt, "ausgelassen"):
      Knopf "Wieder öffnen" macht ihn wieder offen
- [ ] Ausgelassenen Satz doch speichern: der Punkt wird voll
- [ ] Person mit einem Satz je Uebung: kein Auslassen-Knopf, alles wie bisher
- [ ] Sperrbildschirm: ausgelassene Saetze kommen nicht mehr als Quick-Log,
      die Zeile zeigt z.B. "(2/2)"
- [ ] Nach "Workout beenden" und neuem Start am naechsten Tag: Vorschlaege
      fuer Satz 3 kommen aus Satz 2 der letzten Einheit (nichts leer)

## History
- [ ] Tabelle: unter dem Wert des heutigen Tages klein "2/3 Sätze"
- [ ] Datum oben antippen: im Tages-Detail "<Uebung>: Satz 3 ausgelassen (<Name>)"
- [ ] Uebung im Training antippen (Bild) -> Verlauf: "· Satz 3 ausgelassen"

## Auswertung
- [ ] History -> "Auswertung": Zeitraum-Knoepfe, darunter Alle / Push / Pull / Legs / Eigene
- [ ] Rangliste zeigt die Steigerung je Uebung, Gewicht und 1RM umschaltbar
- [ ] Ein Tipp auf eine Zeile springt zu ihrem Diagramm
- [ ] Diagramm antippen und ziehen: oben steht der Wert des Tages
- [ ] "Verlauf ›" oeffnet den gewohnten Einzelverlauf
- [ ] Push / Pull / Legs zeigen nur die Uebungen dieses Workouts
- [ ] "Frei": Von und Bis waehlen; Von nach Bis zeigt einen Hinweis
- [ ] "Eigene": mehrere Uebungen ankreuzen, "Fertig" — nur diese erscheinen
- [ ] App schliessen und wieder oeffnen: History steht wieder auf der
      Auswertung mit derselben Auswahl
- [ ] Andere Person oben waehlen: Werte und Farbe wechseln
