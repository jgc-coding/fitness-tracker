# Handy-Test v2.13.0 (neue Uebung Bizeps Machine)

Vorher: BEIDE Handys ganz schliessen und neu oeffnen, unter Settings steht 2.13.0.

- [ ] Ein Handy, angemeldet und mit Internet: Settings -> "Standard-Uebungen
      laden" meldet "1 Uebungen hinzugefuegt!"
- [ ] Danach Settings -> "Bilder automatisch zuordnen"
- [ ] Katalog: "Bizeps Machine" steht da, mit Vorschaubild, "Arme" und
      "Maschine (Gewichte)"
- [ ] Vorschaubild antippen: die grosse Zeichnung wechselt zwischen
      gestreckten Armen (Scheibe unten) und gebeugten Armen (Scheibe oben)
- [ ] Die Muskelgrafik darunter zeigt den Bizeps kraeftig, die Unterarme
      blasser
- [ ] Planung: die Uebung laesst sich einem Tag hinzufuegen
- [ ] Im Training: das Gewichts-Rad springt in Schritten von 1,25 kg
- [ ] Zweites Handy (angemeldet, neu gestartet): die Uebung steht dort
      ebenfalls, mit Bild, und NICHT doppelt
- [ ] "Standard-Uebungen laden" ein zweites Mal: meldet "Alle Uebungen
      bereits vorhanden."
